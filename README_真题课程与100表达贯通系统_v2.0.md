# 考研英语作文｜真题课程与100表达贯通系统 v2.0

## 文件说明

- `index.html`：可直接部署或本地打开的单文件教学网页，14 张 Part B 真题图片已内嵌，无需额外图片目录。
- `考研英语作文_真题课程与100表达贯通系统_v2.0.html`：版本化网页文件，与 `index.html` 内容一致。
- `考研英语作文_真题-表达映射系统_v2.0.json`：真题、表达卡、句块及其关联关系的结构化数据。

## 当前内容规模

- 2010—2023 英语一写作真题：28 题（每年 Part A + Part B）
- 100 组“词汇 × 句块”表达卡
- 190 个核心高分句块
- 14 张 Part B 真题原图

## 教学逻辑

主线为：

`真题原文 → 拆解任务 → 调用句块 → 学习本题核心词包 → 组装示范 → YOU TURN → 迁移到同类真题`

表达标签分为：

- `本题核心`：当前真题优先掌握的表达。
- `复现练习`：此前已经作为核心表达学习过，本题再次调用。
- `迁移拓展`：编辑层面的语义迁移建议，不表示该表达原词出现在真题中。

网页中的“教学组装示范”属于教学编辑内容，不是官方答案，也不是原始真题来源文本。

## 数据与来源说明

网页保留真题源材料的原始表述。2020 年 Part A 源文本中的 `White a notice` 按来源保留，并在教学界面中说明，不做静默改写。

真题内容、词包和核心句块分别来自项目内的真题母库、100 卡词汇句块联动表以及 v2.0 组装器核心表；教学拆解、路由、组装示范与迁移建议属于课程编辑层。

## 学习进度

完成状态、表达掌握度和 YOU TURN 草稿通过浏览器 `localStorage` 保存：

- 只保存在当前浏览器/当前设备。
- 清除浏览器网站数据后可能丢失。
- 不支持跨设备、跨浏览器自动同步。
- “掌握度”是学生自评，不是系统自动判分。

## GitHub Pages 部署

1. 新建 GitHub 仓库。
2. 将部署包中的 `index.html` 放在仓库根目录。
3. 在仓库 `Settings → Pages` 中选择从主分支根目录部署。
4. 等待 GitHub Pages 生成访问地址即可。

因为页面为单文件版本，图片和课程数据已经嵌入，不需要额外配置静态资源路径。
