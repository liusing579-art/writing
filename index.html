考研英语作文｜词汇 × 句块联动学习

你真正缺的，往往不是更多“高级词”，而是 把高级词稳定写进作文里的能力。

所以这套方法不让你孤立背词，也不让你死背整篇模板，而是把“词义、搭配、句法、写作功能、主题迁移”压缩进一个可反复调用的表达单元。

为什么你背了很多词，作文还是写不出来？

很多同学的学习方式是：important → crucial，bad → detrimental，cause → result in。问题是，真正到考场时你还会卡在三个地方：这个词放哪一段？后面接什么？换一道题还能不能用？

传统背词

exacerbate = 加剧

结果：知道中文，但不会搭配，也不知道什么时候该用。

我们的学习单位

If left unaddressed, [PROBLEM] may exacerbate existing [ISSUE].

一次学会：词义 + 搭配 + 句法 + 写作功能 + 迁移方式。

核心原则：一个句块，不是一道题的答案，而是一类写作任务的答案

按“功能”学，而不是按“题目”背
你不是在背“手机依赖作文”“教育差距作文”，而是在学“如何写危害”“如何写原因”“如何写措施”。
把记忆量压缩下来
一个稳定句块可以跨多个主题复用，换题时只替换槽位，而不是重新背一整篇。
高级表达更安全
句块会同时固定搭配和语法，例如 mitigate + adverse effects，避免只会词义却乱接成分。
高级 ≠ 生僻
我们保留的升级必须满足：更准确、更书面、更可迁移。能写对永远优先于炫词。

为什么它比背整篇范文更省？

看同一个句块怎么跨题迁移。真正稳定的是“写作功能”，变化的是主题词。

If left unaddressed, [PROBLEM] may exacerbate existing [ISSUE].
手机依赖：If left unaddressed, excessive smartphone use may exacerbate existing mental health problems.
教育差距：If left unaddressed, unequal access to quality education may exacerbate existing social inequalities.
网络谣言：If left unaddressed, online misinformation may exacerbate public distrust.
你获得的不是“1个高级词”，而是“1个能覆盖多道题的表达模块”。

为什么这种方法更容易写对？

孤立记词最容易出错，因为你只记得中文意思，却不知道这个词习惯和什么搭配。句块学习直接把搭配固化下来。

只背词

mitigate = 缓解

容易乱写：mitigate people / mitigate sb to do...

背固定搭配

Targeted measures can mitigate the adverse effects of [PROBLEM].

直接记住 mitigate + adverse effects。

作文不是“背出来”的，而是“组出来”的

真正稳定的流程，是先判断你现在要完成什么写作任务，再调用对应句块。

看题
→
判断功能
→
选句块
→
替换主题词
→
组出段落
大作文最常见的功能： 描述 / 寓意 / 重要性 / 好处 / 坏处 / 原因 / 措施 / 结尾。
小作文最常见的功能： 邀请 / 建议 / 推荐 / 通知 / 请求 / 感谢 / 道歉。

高级词不是越难越好

我们不会鼓励你把每个简单词都强行替换成C2词。真正值得学的升级，至少满足下面三个标准。

更准确：能表达更细的意思更书面：适合正式英语写作更可迁移：换题后仍然能用
一段里有 1—2 个明显高级表达 + 1 个高分句块，就已经足够形成层次。其余句子保持自然准确。

新手应该怎么学？

第一步：P1 20条先解决 important / help / cause / problem / solve 这类最常用意思。
第二步：每条至少换2个主题例如 exacerbate 不能只会手机依赖，还要会教育差距、网络谣言。
第三步：P4-A 外刊高迁移再加入 mitigate / impede / foster / underpin / resilience / disparity 等。
“学会”的标准：看到中文意思，能写出核心句块；换一个主题，仍然能自己把槽位填对。

30秒体验：一个句块怎么变成三道题的答案
